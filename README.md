# Система учета обучающихся АНО «Цифровая экономика УР»

## Описание проекта

Система учета обучающихся — веб‑приложение для автоматизации процессов управления заявками и студенческим контингентом в образовательной организации. Проект направлен на замену ручного учета на базе Google‑таблиц современным цифровым решением.

## Основные функциональные возможности

- **Обработка и учет заявок** — автоматизированный прием, валидация и ведение заявок поступающих.
- **Управление студенческими данными** — хранение и актуализация персональных и учебных данных обучающихся.
- **Формирование групп** — распределение студентов по учебным группам и программам.
- **Ведение личных дел** — централизованное хранение документов и истории изменений по каждому студенту.
- **Интеграция с внешними источниками** — синхронизация данных с официальным сайтом организации, выгрузка в ФРДО и Росстат.
- **Формирование отчетности** — экспорт данных в Excel, генерация аналитических и регламентированных отчетов.

## Технологический стек

- **Backend:** ASP.NET Core.
- **Frontend:** React.js.
- **База данных:** PostgreSQL.
- **Архитектура:** клиент‑серверная.
